# AR Algorithm Lab — образовательный WebAR-проект

**Предмет:** информатика, 9–11 классы. **Раздел:** алгоритмы и программирование.

## Содержимое
- `index.html` — интерактивная лаборатория: линейный алгоритм, ветвление, цикл, шаги, 3D AR, тест.
- `marker.html` — печатный маркер HIRO (из официального репозитория AR.js; загружается через интернет).
- `qr.html` — генератор QR-кода для уже опубликованного адреса.

## Опубликовать бесплатно на GitHub Pages
1. Создайте публичный репозиторий, например `ar-algorithm-lab`.
2. Загрузите три HTML-файла из архива в корень репозитория (через Add file → Upload files → Commit changes).
3. Откройте Settings → Pages → Build and deployment; Source: Deploy from a branch, Branch: main / (root); сохраните.
4. Откройте выданный HTTPS-адрес вида `https://username.github.io/ar-algorithm-lab/`.
5. На этом же сайте перейдите в `qr.html`, убедитесь, что указан актуальный URL, и распечатайте QR.
6. На отдельном листе или другом устройстве откройте `marker.html` и распечатайте маркер HIRO.
7. На телефоне отсканируйте QR, нажмите «Запустить AR», разрешите доступ к камере, наведите ее на маркер.

**Не путать:** QR запускает *сайт*. HIRO определяет место, где рисуется виртуальная трехмерная схема.

## Учебное занятие (40 минут)
- 5 минут — постановка цели, повторение понятия алгоритма.
- 10 минут — исследование линейного алгоритма y = 2x + 3 для x = 4 и x = −2.
- 10 минут — исследование ветвления для x = 6 и x = 7; прогноз результата до запуска.
- 10 минут — изучение цикла суммирования от 1 до 4, пошаговый запуск и объяснение счетчика.
- 5 минут — тест из трех вопросов, обсуждение результатов.

## Критерии оценивания (10 баллов)
- Верный прогноз результата алгоритмов — 3 балла.
- Объяснение трех типов алгоритмов — 3 балла.
- Правильные ответы на встроенный тест — 3 балла.
- Умение найти и исправить собственную ошибку — 1 балл.

## Совместимость и ограничения
- Встроенная 2D-лаборатория выполняет задания без камеры.
- Трехмерная AR-часть построена на A-Frame 1.6.0 и AR.js 3.4.8, загружаемых через CDN при подключении к интернету.
- Для камеры необходим HTTPS либо localhost; пользователь должен дать разрешение.
- Для AR нужен хорошо освещенный маркер HIRO и браузер с доступом к камере и WebGL.
- Проверка ответов производится в браузере. База данных и аккаунты не используются.
- Реальный публичный URL и действующий QR нельзя предоставить до размещения сайта на хостинге.

## Важное
Архив содержит исходный код; не утверждается, что проект уже развернут в интернете или проверен на конкретном телефоне. Если браузер/камера не поддерживается, 2D режим остается доступным.
